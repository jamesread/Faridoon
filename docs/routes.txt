# Faridoon HTTP / Connect routes

SPA (Vue Router) is served for browser paths. API is ConnectRPC under
`/faridoon.v1.FaridoonService/*`.

## Privileges

SUPERUSER — admin gate (implies all privileges)
APPROVE_QUOTES — approvals queue; quote edit; reject pending
BYPASS_APPROVAL — new quotes skip approval queue

Unapproved quotes are only readable by approvers or the submitting user.
Voting is limited to existing approved quotes when `enable_voting` is on.
Feature toggles and listing size (`quotes_per_page`, voting, registration, guest add, syntax highlighting, site title) are cvars under /admin/settings.
The last SUPERUSER cannot be demoted, deleted, or have SUPERUSER revoked from their only granting group.
